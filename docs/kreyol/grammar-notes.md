# 🧩 Notes de grammaire — créole guadeloupéen (gcf)

> Points de grammaire employés dans le projet, avec la forme guadeloupéenne retenue et les formes d'autres créoles à **ne pas** utiliser.
> Niveaux de source : voir [sources.md](sources.md). Les points non tranchés renvoient à [variants.md](variants.md).

---

## 1. Groupe nominal

| Point             | Forme retenue (GUA)                                       | Exemple du projet        | À exclure                 | Source |
| ----------------- | --------------------------------------------------------- | ------------------------ | ------------------------- | ------ |
| Défini singulier  | `N-la`, invariable                                        | `sous-la`, `montangn-la` | `-a`, `-an`, `-lan` (MAR) | A      |
| Défini pluriel    | `sé N-la`                                                 | `sé ti ma-la`            | `N-yo` (HT, GUY)          | B      |
| Démonstratif      | `N-lasa`                                                  | `dlo-lasa`, `jou-lasa`   | `-tala` (MAR)             | A      |
| Indéfini          | `on`                                                      | `on gwo krab`            | `an` (MAR)                | B      |
| Article agglutiné | le « la/l/z » français fait partie du mot, `-la` s'ajoute | `larivyè-la`, `zannimo`  | —                         | A      |

## 2. Possessifs et pronoms

| Point                  | Forme retenue                                                                            | Exemple                             | Source |
| ---------------------- | ---------------------------------------------------------------------------------------- | ----------------------------------- | ------ |
| Possessif              | `N a-y` (son), `N a-w` (ton), `N an mwen` (mon), `N an nou` (notre), `N a zòt`, `N a yo` | `kaz a-y`, `dlo a-w`, `dlo an mwen` | A, B   |
| Pronoms (long / court) | `mwen` / `an`, `vou` / `ou`, `-w` ; `li` / `i`, `-y` ; `nou` ; `zòt` / `zò` ; `yo`       | `plen-y`, `jwenn-li`, `pou-y`       | B      |
| `i`                    | sujet seulement ; après verbe ou préposition : `li` / `-y`                               | `i plen-y`                          | B      |

## 3. Temps, aspect, négation

| Point                                 | Forme                                      | Exemple                   | Source                      |
| ------------------------------------- | ------------------------------------------ | ------------------------- | --------------------------- |
| Passé / état passé                    | `té`                                       | `Ti Kannot té piti`       | B                           |
| Progressif, habituel, vérité générale | `ka`                                       | `Chak gout dlo ka konté`  | A, B                        |
| Imparfait narratif                    | `té ka`                                    | `larivyè-la té ka chanté` | B                           |
| Futur                                 | `ké`                                       | `nou ké gadé`             | A                           |
| Futur négatif                         | `pé ké` (`pa` → `pé` devant `ké`)          | `pé ké ni dlo ankò`       | A (Facthum-Sainton 2014)    |
| Négation                              | `pa` devant le verbe et devant `té` / `ka` | `Lapli pa té ka tonbé`    | B                           |
| « aucun, personne »                   | `pon … pa`                                 | `pon moun pa té bizwen`   | B ; `pyès` = MAR, à exclure |

## 4. Phrase

| Point                            | Forme                 | Exemple             | Source |
| -------------------------------- | --------------------- | ------------------- | ------ |
| Pas de copule devant un adjectif | `N + adj.`            | `solèy-la té cho`   | B      |
| `sé` devant un groupe nominal    | `Sé dlo pou nou tout` | —                   | B      |
| Clivée                           | `Sé X ki …`           | `Sé mwen ki pli fò` | B, C   |
| Interrogation                    | `Ès …?`               | `Ès mwen pé édé ?`  | A, C   |
