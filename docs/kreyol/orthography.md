# ✍️ Orthographe — conventions du projet (gcf)

> **Système retenu** : graphie GEREC, pratique guadeloupéenne de type **GEREC 1** (accents et `y` systématiques).
> Source principale : cours _Phonographématique créole_, Univ. de Lorraine (niveau A) — voir [sources.md](sources.md).
> Chaque règle indique son écart avec GEREC 2, pour lire les sources qui l'emploient.

---

## 🧠 Mental Model

```
son entendu ──► une lettre (ou digramme) ──► jamais de lettre muette
   [ʁ] + o/ou/ò   ──► w      gwo, wouj, wòch, wobinè, bwouyon
   [j]            ──► y      pyébwa, larivyè, syèl
   [ɛ] [ɔ] fermés ──► è ò    règ, sèk, wòch, Ès
   nasales        ──► an en on (+ n double si consonne nasale prononcée : lanmè, montangn)
```

## 1. Règles

| #   | Règle                                                                                       | Exemples du projet                                         | GEREC 2                                                                               |
| --- | ------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 1.1 | Pas de lettre muette                                                                        | `bò` (bord), `ven` (vingt), `Gwadloup`                     | identique                                                                             |
| 1.2 | `r` devant ou après une voyelle arrondie (`o`, `ou`, `ò`) s'écrit `w`                       | `gwo`, `wouj`, `wòch`, `pwotéjé`, `wobinè`, `bwouyon`      | identique                                                                             |
| 1.3 | `è` / `ò` toujours accentués, y compris en syllabe fermée                                   | `règ`, `sèk`, `fèy`, `wòch`, `zòt`, `swèf`, `Ès`, `kréyòl` | accent omis en syllabe fermée (`reg`, `woch`, `Es`)                                   |
| 1.4 | Semi-consonne [j] notée `y`                                                                 | `pyébwa`, `larivyè`, `syèl`                                | `i` après consonne (`piébwa`)                                                         |
| 1.5 | Voyelles nasales `an`, `en`, `on` ; `n` doublé quand la consonne nasale se prononce         | `lanmè`, `lannuit`, `montangn`                             | identique                                                                             |
| 1.6 | Soudure des mots figés                                                                      | `onlo`, `adan`, `anmitan`, `lapli`, `zannimo`, `larivyè`   | identique                                                                             |
| 1.7 | Trait d'union entre le nom et `-la` / `-lasa`                                               | `sous-la`, `dlo-lasa`, `jou-lasa`                          | identique                                                                             |
| 1.8 | Trait d'union pour les pronoms courts et les possessifs (convention du dictionnaire Ludwig) | `a-y`, `a-w`, `plen-y`, `jwenn-li`                         | apostrophe : `a'y`, `plen'y` — **choix à confirmer, voir [variants.md](variants.md)** |
| 1.9 | Marques de temps et d'aspect en mots séparés                                                | `té ka`, `pé ké`                                           | identique                                                                             |

## 2. Typographie

- Guillemets `« »` avec espaces, espace avant `! ? :` (typographie française).
- Dialogues introduits par `– ` (tiret demi-cadratin).
- `Kréyòl` avec majuscule comme nom de langue (sélecteur de langue), `kréyòl` comme adjectif (`Lang kréyòl`).
- Le kréyòl du projet ne contient pas d'apostrophe ; côté français, l'apostrophe droite `'` est majoritaire (`L’eau` est l'exception).
