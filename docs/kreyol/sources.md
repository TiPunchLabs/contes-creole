# 📚 Sources linguistiques — créole guadeloupéen (gcf)

> Référentiel des sources utilisées pour le kréyòl du projet, avec leur niveau d'autorité et leur état de consultation.

---

## 1. Hiérarchie de confiance

| Niveau | Type                                                                           | Exemples                                                                                   |
| ------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| **A**  | Manuels de graphie guadeloupéenne, GEREC, ouvrages linguistiques guadeloupéens | Facthum-Sainton, Bernabé, cours _Phonographématique créole_                                |
| **B**  | Dictionnaires et grammaires de référence                                       | Ludwig / Montbrand / Poullet / Telchid, APiCS, CNRS LGIDF, Déterville, Tourneux & Barbotin |
| **C**  | Corpus académiques                                                             | Ludwig/Telchid, CREOLORAL, APiCS, POTOMITAN, Kreyol-MT                                     |
| **D**  | Ressources collaboratives                                                      | Diko Kréyol, PanLex, Tatoeba, Wiktionnaire, datasets communautaires                        |
| **E**  | Web générique                                                                  | blogs, réseaux sociaux, Common Crawl                                                       |

> ⚠️ **Règle** : une source D ou E ne renverse jamais une règle attestée en A ou B. Un corpus fournit des exemples, pas une norme. Une forme trouvée seulement sur le Web n'est jamais normative.

- L'accès au jeu de données POTOMITAN (Hugging Face, accès restreint).
