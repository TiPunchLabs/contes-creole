# 🔀 Variantes — acceptées, exclues, à valider

> Une variante régionale guadeloupéenne n'est **pas** une erreur. Si deux formes sont légitimes, on garde l'original, sauf convention dominante du projet : on signale alors
> « Variante attestée, mais différente de la convention utilisée majoritairement dans le projet. »

---

## 1. Variantes acceptées (guadeloupéennes)

| Forme du projet                         | Variante légitime                                                  | Statut                                             |
| --------------------------------------- | ------------------------------------------------------------------ | -------------------------------------------------- |
| `ou` / `vou` (alternance libre)         | —                                                                  | les deux restent ; `vou` = forme longue, accentuée |
| `mwen` (partout)                        | `an` (forme courte de « je »)                                      | registre, pas une erreur                           |
| `anmitan`                               | `an mitan`                                                         | `anmitan` = convention du projet                   |
| `toubònman`                             | `toubòlman` (seule forme attestée en A et C)                       | **À VALIDER**                                      |
| `vè` (vert)                             | `vèt`                                                              | **À VALIDER**                                      |
| `a-y`, `plen-y` (trait d'union, Ludwig) | `a'y`, `plen'y` (apostrophe, GEREC 2 ; majoritaire dans Kreyol-MT) | **choix global à faire**, sans changer d'ici là    |

## 2. Formes exclues (autres créoles)

| Forme                        | Créole            | Forme guadeloupéenne           |
| ---------------------------- | ----------------- | ------------------------------ |
| `N-yo` (pluriel)             | haïtien, guyanais | `sé N-la`                      |
| `-tala` (démonstratif)       | martiniquais      | `-lasa`                        |
| `-a`, `-an`, `-lan` (défini) | martiniquais      | `-la` invariable               |
| `pyès`                       | martiniquais      | `pon`                          |
| `toutotan`                   | haïtien           | à valider (`toutan` ? `tan` ?) |
| `an` (article indéfini)      | martiniquais      | `on`                           |
