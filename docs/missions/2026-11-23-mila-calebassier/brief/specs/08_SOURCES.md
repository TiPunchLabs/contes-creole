# Sources et documentation

Documentation officielle à consulter dans les versions réellement installées. Les détails API et extensions évoluent ; ne pas copier un exemple d’une autre version sans vérification.

- Blender — export glTF : https://docs.blender.org/manual/en/latest/addons/scene_gltf2.html
- Blender — Python API : https://docs.blender.org/api/current/info_quickstart.html
- Three.js — GLTFLoader : https://threejs.org/docs/pages/GLTFLoader.html
- Three.js — système d’animation : https://threejs.org/manual/pages/animation-system.html
- Three.js — AnimationMixer : https://threejs.org/docs/pages/AnimationMixer.html
- Three.js — gestion des couleurs : https://threejs.org/manual/pages/color-management.html
- Three.js — libération des ressources : https://threejs.org/manual/pages/cleanup.html

Principes fondés sur ces documentations : animations/clips compatibles à contrôler après chargement, limites de l’export Blender, espaces colorimétriques à gérer, ressources GPU et bitmaps à libérer explicitement selon leur ownership. Les choix de budgets, d’organisation, de style et de caméras du dossier sont des directives de mission, pas des prescriptions des documentations.

Pistes artistiques explorées dans la conversation : lavis et dessins de décors de « La Princesse Kaguya » ; matières d’animation peintes de l’ONF. S’inspirer de principes généraux (économie de détail, respiration, pigments), sans recopier leurs plans ou personnages.
- ONF, Immersion : https://www.nfb.ca/film/immersion/
- Présentation de l’exposition Isao Takahata, mudac : https://mudac.ch/wp-content/uploads/2026/04/DP_Takahata_EN.pdf
